# Stock Order Webhook Refactor

## ✅ Changes Made

### **Before (Causing Duplicates):**
```
Order Submission
  ├─ submitOrderLine webhook × N (one per line item)  ❌ REMOVED
  ├─ notifyOrderPlaced webhook × 1                    ✅ ENHANCED
  └─ notifyOrderManifest webhook × 1                  ❌ REMOVED
```

**Problem**: Multiple webhooks potentially creating duplicate `Stock_Order` records.

---

### **After (Single Array Webhook):**
```
Order Submission
  └─ notifyOrderPlaced webhook × 1                    ✅ ONE CALL
       ├─ Contains: lineItems array (full data)
       └─ n8n loops through array to create Stock_Order records
```

**Solution**: ONE webhook call with ALL line items in an array.

---

## 🔧 n8n Workflow Structure

### **Your n8n workflow should:**

```
1. Webhook Trigger
   ├─ Receives payload from React app
   │
2. Loop Over Items (lineItems array)
   ├─ For each item in payload.lineItems:
   │   └─ Create Airtable Record in Stock_Order table
   │       ├─ Order Id: {{ $json.autoGeneratedOrderId }}  ← NUMERIC!
   │       ├─ Device Type: {{ $json.deviceType }}
   │       ├─ Date Ordered: {{ $json.dateOrdered }}
   │       ├─ Quantity ordered: {{ $json.quantityOrdered }}
   │       ├─ Contractor Company: {{ $json.contractorCompany }}
   │       ├─ Region: {{ $json.region }}
   │       ├─ Technician: {{ $json.technician }}
   │       ├─ Ordered by: {{ $json.orderedBy }}
   │       ├─ Order Location: {{ $json.orderLocation }}
   │       ├─ Deliver to Part: {{ $json.deliverToPart }}
   │       ├─ Recipient Name: {{ $json.recipientName }}
   │       ├─ Item Description: {{ $json.itemDescription }}
   │       ├─ Item Category: {{ $json.itemCategory }}
   │       ├─ Item Nature: {{ $json.itemNature }}
   │       └─ Item Url: {{ $json.itemUrl }}
   │
3. After Loop Completes
   ├─ Aggregate Items Node
   │   └─ Collect all created Stock_Order records
   │
4. Send Email Notification
   ├─ To: {{ $json.orderedBy }}
   ├─ Subject: Order {{ $json.orderId }} Placed Successfully
   ├─ Body: 
   │   - Order ID: {{ $json.orderId }}
   │   - Total Items: {{ $json.totalItems }}
   │   - Total Quantity: {{ $json.totalQuantity }}
   │   - Items list from {{ $json.items }} array
   │
5. (Optional) Update Unique_Orders
   └─ Mark order as "Submitted" or similar status
```

---

## ⚠️ Critical: Use Numeric Order ID

In your **Airtable Create Record** node for `Stock_Order`:

```javascript
// ✅ CORRECT - Use numeric ID
Order Id: {{ $json.autoGeneratedOrderId }}  // Results in: 11

// ❌ WRONG - Don't use formatted string
Order Id: {{ $json.orderId }}  // Results in: "ORD-0011"
```

**Why?** You changed `Stock_Order.Order Id` to a **Number** field in Airtable. It must receive `11`, not `"ORD-0011"`.

### **Keep and update:**

## 📊 Duplicate Prevention

This refactor prevents duplicates by:

1. ✅ **Single webhook call** - no race conditions
2. ✅ **Array processing** - n8n controls the loop
3. ✅ **Sequential execution** - records created one by one in order
4. ✅ **Transaction-like behavior** - if loop fails, can retry entire batch

| Possible duplicates | No duplicates |
