## Features

### Stock Ordering
- Web-based order submission
- Business line logic (Absa/Cash Connect)
- Automatic warehouse notifications
- Status tracking

### Warehouse Picking
- Pick queue for pending orders
- USB barcode scanner input
- Real-time duplicate detection
- Progress tracking

### Dispatch
- Multiple dispatch methods
- Waybill tracking
- PDF manifest generation
- Automated notifications

### Technician Registry
- Central database
- Contact and region management
- Dispatch integration

### Inventory Control
- Stock level visibility
- Cycle counting
- Alert thresholds
- Reporting

### Asset Tracking
- Serial number tracking
- Status and location
- Image documentation

### AI Assistant
- Built-in help system
- Answers questions from your docs
- Navigation guidance

## Technical Stack

**Frontend:** React + TypeScript
**Database:** PostgreSQL (Supabase)
**Automation:** n8n workflows
**Hosting:** Netlify CDN

**Access:**
- Warehouse: Desktop/laptop + USB scanners
- Field: Mobile browser with camera scanning
