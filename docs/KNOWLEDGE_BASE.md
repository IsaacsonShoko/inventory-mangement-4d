## Stock Ordering

### Creating an Order
1. Click **Stock Order** from dashboard
2. Select business line (Absa/Cash Connect)
3. Fill required fields
4. Add items
5. Submit

### Tracking Orders
1. Go to **Tracking** page
2. Search by order number or recipient
3. View status: Pending → Picked → Dispatched

---

## Warehouse Picking

### Pick Queue
1. Go to **Picking Queue**
2. View pending orders
3. Click order to start picking

### Picking Cart
1. Scan or enter serial numbers
2. System validates in real-time
3. Progress bar shows completion
4. Submit when all items picked

**Note:** Duplicates are blocked automatically

---

## Dispatch

### Dispatch Queue
1. Go to **Dispatching**
2. View picked orders ready for dispatch
3. Click order to dispatch

### Dispatch Cart
1. Select method: Collection, Delivery, or Courier
2. Enter waybill (if required)
3. Generate PDF manifest
4. Submit dispatch

## Inventory Management

### Stock Counts
1. Go to **Stock Counts**

3. Enter counts by location
4. System calculates variances
5. Submit when complete

### Stock Alerts
*(Back Office only)*
1. Go to **Stock Alerts**
2. View low stock items
3. Set alert thresholds

## Troubleshooting

### Can't Login
- Check email verification
- Reset password if needed
- Contact admin if account pending approval

### Scanner Not Working
- Ensure USB scanner is plugged in
- Try scanning in a text field first
- Check scanner keyboard wedge mode

### Page Not Loading
- Check internet connection
- Clear browser cache
- Try different browser

### Permission Denied
- Check your user role
- Contact admin for access

## Best Practices

**Stock Counting:**
- Count zone by zone
- Two-person verification for high-value items
- Submit daily progress

**Picking:**
- Scan serials one at a time
- Check screen for validation
- Don't force submit on errors

**Dispatch:**
- Verify recipient details
- Download manifest before submitting
- Keep waybill numbers accurate

## FAQ

**Q: Can multiple users pick the same order?**
A: No, orders are locked to one picker at a time.

**Q: What if I scan the wrong serial?**
A: Delete it from the list before submitting.

**Q: How do I generate reports?**
A: Go to KPI Dashboard (Back Office access required).

**Q: Can I use this offline?**
A: Limited offline mode for field operations. Full sync when reconnected.

**Q: How do I request new features?**
A: Email [Your Email] with suggestions.
